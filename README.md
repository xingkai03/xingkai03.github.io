# Personal website

The calories app at `/calories/` lives in its own repository,
[xingkai03/calories](https://github.com/xingkai03/calories), which GitHub Pages serves at that path.

SVT Learn (`/svt-learn/`) moved into the Svenska web app,
[xingkai03/svenska-vocab](https://github.com/xingkai03/svenska-vocab), served at `/svenska-vocab/#/svt`;
`/svt-learn/` now forwards there.

## Site

Built with [Astro](https://docs.astro.build) from the blog starter. `npm run dev` serves it at
`localhost:4321`, `npm run build` writes `dist/`, and pushes to `main` deploy to GitHub Pages.
